नेपाली रोमनाइज्ड टाइपिङ गाइड (how the Nepali phonetic keys work)

Type Nepali the way it sounds using English letters — this converts it to Unicode Devanagari live, letter by letter.

Long vowels: double the letter or capitalize — aa/A = आ/ा, ee/I = ई/ी, oo/U = ऊ/ू
Other vowels: i=इ/ि, u=उ/ु, e=ए/े, o=ओ/ो, ai=ऐ/ै, au=औ/ौ
Retroflex (capital) vs dental (lowercase): T/Th/D/Dh/N = ट/ठ/ड/ढ/ण  ·  t/th/d/dh/n = त/थ/द/ध/न
Aspirates: kh gh chh jh ph bh = ख घ छ झ फ भ
Sibilants: sh=श, S=ष, s=स  ·  Conjuncts: ksh=क्ष, gya=ज्ञ, tra=त्र, shr=श्र
Special: M=ं (anusvar), ~=ँ (chandrabindu), .=। (full stop → danda)

This is a best-effort phonetic engine, not the official government layout — spellings may occasionally need a different key combination than you'd expect (e.g. krishna renders as क्रिश्न, not कृष्ण). Practice will make the pattern intuitive.
